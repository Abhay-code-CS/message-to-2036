# 🌌 Message to 2036

**A message from your present self to your future self.**

Message to 2036 is a cinematic, space-inspired digital time capsule created using HTML and CSS. It represents a message written in 2026, meant to be remembered ten years later.

## ✨ Features

- 🌠 Space-inspired starfield background
- 🔵 Floating planet animation
- 💌 Minimal digital letter design
- 🌌 Dark, cinematic UI
- 📱 Responsive layout for mobile and desktop
- ⚡ Pure HTML and CSS — no JavaScript required

## 🛠️ Built With

- HTML5
- CSS3
- CSS Animations
- Google Fonts — Space Grotesk

## 📂 Project Structure

```text
message-to-2036/
├── index.html
├── style.css
└── README.md
```

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

## 🎯 Project Goal

To explore creative web design and CSS animations while building a simple, visually engaging digital time capsule.

**Note:** This is currently a static UI concept. Message storage and automatic delivery in 2036 are not implemented.
